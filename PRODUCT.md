# Agent runtime controls

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Existing DSH browser module loader, React and authenticated connection RPC.

## Users and purpose

The workstation user operates native DSH, Cursor and Factory Droid sessions from
one chat. The runtime panel manages continuation, cancellation, decisions,
events, usage and artifacts without replacing the provider's harness.

## Confirmed constraints

The user chose all three adapters, Missions, a panel alongside chat, explicit
role routing and Git worktree isolation. Missions require a separate explicit
confirmation. Preserve DSH's incumbent UI, themes, locale and settings slots.
Provider capabilities may differ; absent usage is not zero usage. Runtime
history and credentials remain local. The panel cannot invent native parent
authority; native sessions must begin through a chat tool.
